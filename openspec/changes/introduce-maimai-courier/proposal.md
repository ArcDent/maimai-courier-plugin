## Why

把转发功能从复读插件独立为“麦麦搬运喵”，让源群 Maisaka 自主决定分享，并通过一个简单工具完成转发及可选评论。取消旧概率决策、目标群决策票和额外上下文注入，避免两个插件同时处理转发。

## What Changes

- 新增独立插件 `maimai-courier-plugin`，自动入口仅关注白名单源群的合并转发，唤起源群 Maisaka 自主判断，可选择沉默。
- 新增工具 `forward_message(message_id, target_group_id, comment="")`：转发本群指定消息到白名单目标群，支持普通文字、图片和合并转发；不支持或无法完整恢复的内容明确拒绝。
- 转发成功后，非空评论固定等待 **0.5 秒**再发送；空评论只转发、不等待。评论由调用方提供，不再唤起目标群生成。
- 两次发送均走主程序正常发送、存储和 Maisaka 历史同步，不调用 `maisaka.context.append`。
- 成功投递持久防重，跨重启拒绝同一源消息向同一目标群重复发送；保护并发、部分成功及结果不确定场景。
- **BREAKING**：不沿用旧工具参数、概率、决策票、强制查看续轮、延迟区间配置和转发注入协议。配套旧项目变更 `remove-cross-group-forward` 完整删除旧功能。
- 同步已批准的两份本地 runbook；建立同源 `AGENTS.md` / `CLAUDE.md` 软链接规则。

## Capabilities

### New Capabilities

- `cross-group-forward`: 源群自主决策、三参数工具、消息归属与目标白名单、真实发送与自然上下文、固定延迟评论、持久防重和生命周期。

### Modified Capabilities

无；本项目尚无主规格。

## Impact

- 本项目新增插件入口、配置、最小转发逻辑及状态存储、manifest、测试与开发文档；不依赖旧插件可导入。
- 依赖 MaiBot SDK 与 Host 的工具执行、消息查询、聊天流、发送和历史同步能力。主程序/消息网关契约须在实现前核实，禁止凭空假定 API 或媒体保真。
- 配套项目为同级 `repeat-plugin`；本变更不修改其业务代码，清理由该项目独立变更承载。
- 运行时状态存储在 Host 授予的数据目录；不复制旧运行配置、凭证或未经归属核实的投递记录。
- 非目标：复读、表情回应、任意跨群读取、所有媒体类型无条件支持、主动清理线上历史数据或自动部署。
