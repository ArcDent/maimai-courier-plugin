# 尚未复核的服务端契约与联验门槛

日期：2026-10-02。本轮没有 SnowLuma 服务端源码，也没有授权真实端点/QQ联验。
01/02核对 `arclinux` 部署目录客户端与宿主源码，02另补公开SDK 2.8.0固定版本证据；
03/04按D10冻结离线假设。
旧研究的参考版本不能代替运行版本，截图不能证明账号、路由、权限或响应隔离。

## 证据强度

- A：本轮重新读取的宿主/适配器源码及哈希，只证明该源码的行为；02另有本轮重读的
  公开SDK 2.8.0固定提交与发布包一致性证据，只证明该版本契约，不证明线上已加载。
- B：旧研究报告引用的服务端参考源码，本轮未复读；不称服务端已复核。
- C：本仓库旧实现/合成样本，是复用或测试依据，不是外部行为证据。

每项均为**未复核**，只能在另行授权后用服务端源码或受控真实联验确认：

1. **U1 握手与认证**（A+B线索）：实际端点/路径、仅 Bearer 头是否被接受、Token校验和
   动作权限、TLS保护。适配器同时发送 URL token，不能由此证明仅头可用。
   插件冻结仅头认证；失败不退回URL凭证、不跟重定向、不自动选另一个端点。
2. **U2 Universal与多客户端**（A+截图转述）：事件广播范围、自发上报开关、动作响应
   是请求连接独收还是广播、echo是否完整回显。离线实现必须能丢弃别人的响应和伪装事件，
   **即便广播也不能串回执**。服务端限帧/限连/空闲超时同样尚未确认。
3. **U3 身份和源记录**（A+B）：`get_login_info.data.user_id` 实际含义；同账号下
   `get_msg(message_id)` 缓存命名空间、返回 `message_id/message_type/group_id/message`，
   `get_group_list.data[].group_id` 的目标可用含义。宿主ID保留链已核对但实际在线来源
   未确认；未知来源、错ID/群/账号和无数据均在无发送副作用的准备阶段明确拒绝。
4. **U4 固定发送与文本/卡片字段**（B+C）：`send_msg` 群分支参数、结构化文本不解析
   CQ语法、`forward.data.id` 复用已有资源、不展开或上传内部节点。唯一动作已冻结，
   字段不接受时不换 `send_group_msg/forward_group_single_msg` 探测重发。
5. **U5 图片字段与安全获取**（B+C，A有不同候选）：HTTPS `image.data.url` 是否被接受、
   是否能完整重放单图/多图/图文；网关对DNS、重定向、私有地址和文件的处理。
   旧本地字面量校验不足以证明远端获取安全；base64/file在客户端编码中存在，但服务端
   接受性未核实。**上线前必须确认安全获取前提**；不成立就回规划选安全重放方案，
   不能以unknown补救越界访问、不能全部拒图后宣称图片支持已实现。
6. **U6 卡片客户端效果**（B）：资源跨群可用、有效期、内部回复/提及与外部提醒、
   外层预览差异。仅假设内部资源保留，不能承诺客户端展示或不提醒已实测。
7. **U7 真实目标证据**（B+C）：动作回执 `data.message_id`、同ID查询的
   `message_id/group_id/user_id/message_seq`；正整数 `message_seq` 是否确为QQ群序列，
   无序列时本地不透明ID分支。没有四项充分证据就unknown，资源ID/数字格式都不能替代。
8. **U8 发送失败与登记顺序**（B+C）：QQ发送→生成/保存回执的真实顺序、发送后登记异常，
   错误码是否可能在副作用后产生。当前一律不据通用错误码/异常文本宣称未发；
   只有本插件能证明尚未进入写入才明确未提交，其余真实成功或unknown。

## 放行含义

第1组勾选只表示源码可证事实已核对、显式假设/样本/继任接口和完整基线已记录，允许
后续组**离线实现与独立评审**；不表示这些服务端条目已确认，也不授权部署、读凭证或发群。

- 发送前预检失败：可以明确拒绝，不要机械套用unknown。
- 已可能提交且证据不足：unknown、占位阻断，不补评论、不重放、不换动作或通道。
- 回执充分但持久化失败：保存已知目标事实的诚实结果，不称完整成功或可靠评论。
- 涉及资源获取安全的假设：在允许真实流量前确认；不能靠发送结果分类替代安全边界。
- 授权联验必须逐项记录确认来源与结果；任一假设被推翻影响范围/安全/可行性时回到规划，
  不允许实现者临时改变字段或成功口径。U1–U8 服务端条目当前全部保持未确认。
