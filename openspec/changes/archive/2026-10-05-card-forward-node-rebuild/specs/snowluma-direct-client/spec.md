## MODIFIED Requirements

### Requirement: 同账号查询与源材料可信性

直连实际登录账号 MUST 与可信宿主调用账号一致；目标群 MUST 为该账号可确认的合法目标。插件 MUST 先验证宿主源消息归属，再按已核实的标识对应关系查询同账号源消息并验证群归属，不能仅凭可解析的 ID 就认定对应关系成立。合并转发卡片的发送材料 MUST 来自按该源消息卡片标识的展开查询结果：插件只提交平台返回的节点序列（发送者标识与显示名经压平限长，内容段按查询结果原样），MUST NOT 向平台提交调用者提供的卡片资源 ID、消息正文或媒体地址，也 MUST NOT 递归展开或重建节点。卡片节点内容中的媒体引用 MUST 取自该展开查询结果，MUST NOT 接受模型或调用者指定的任意 URL、本机路径或内网地址。请求中断或账号变化 MUST 使旧核验失效，不得在核验后静默切换账号发送。

#### Scenario: 错误账号
- **WHEN** 服务端实际登录账号与可信工具调用账号不同
- **THEN** 在源查询或发送前拒绝，不切换账本键规避差异，不使用另一个端点或账号重试

#### Scenario: 查询返回另一群
- **WHEN** 查询响应中的源群与可信源群不符
- **THEN** 不发送、不把响应正文泄露给模型、不使用其资源构造消息

#### Scenario: 标识对应不足
- **WHEN** 只有宿主内部消息标识，且无法确认对应的平台源消息标识
- **THEN** 明确拒绝，不能截取、重编码或猜测标识后发送

#### Scenario: 核验后连接重建
- **WHEN** 已核对账号的核验完成后，发送前发生请求超时、连接中断、端点配置变化或插件退出
- **THEN** 该阶段不自动继续发送；旧核验失效，只有后续合法新调用在重新核验并通过账本防重后才可能发送

#### Scenario: 卡片资源由平台重建
- **WHEN** 转发合并转发卡片消息
- **THEN** 插件提交按源消息卡片标识展开查询取得的节点序列，不提交、不猜测卡片内部资源 ID；卡片资源由平台按目标群上下文重建（含重新上传卡片内媒体），与旧通道「按标识重建时下载旧签名 URL」的失败模式无关

### Requirement: 真实回执与安全结果分类

一次源或评论发送 MUST 最多提交一个发送动作。只有合法动作响应与可核实的真实平台目标消息身份一致时，才允许确认发送成功；仅有非空消息 ID、资源 ID 或受理标志 MUST NOT 视为成功。平台目标消息 ID MAY 为负值，核验 MUST 按返回原值逐字比对，MUST NOT 假设其为正整数。回执核验 MUST 确认目标群、发送账号及平台消息证据（含正整数平台群消息序列），查询次数 MUST 有限且仅针对该次返回的目标标识，MUST NOT 通过再次发送来核实。业务失败响应（如 `retcode=100` 表示查询目标不存在）属明确业务结果，不改变「未提交即明确未发送、已提交无证据即待核实」的分类。模糊失败、未知返回状态、缺失关键证据、查询超时、取消及无法判断是否已提交的异常 MUST 保守归为待核实，不能用通用错误码猜成可重试失败。

#### Scenario: 成功响应但标识不足
- **WHEN** 动作报告成功但没有可核实的真实目标消息标识
- **THEN** 不报告完整成功，不自动重试，源未知时不发送评论

#### Scenario: 回执不属于本次投递
- **WHEN** 查询所得目标群、发送账号或平台消息证据与本次请求不匹配
- **THEN** 保持待核实，不把其他群或其他账号的消息记为本次成功

#### Scenario: 负数目标消息 ID
- **WHEN** 发送动作返回负值消息 ID
- **THEN** 按原值回查并核验四项证据，不因符号拒绝，也不改写为其他形式

#### Scenario: 额外资源标识不是证据
- **WHEN** 卡片发送动作在目标消息 ID 之外返回资源类标识（res_id / forward_id）
- **THEN** 资源类标识 MUST NOT 作为成功证据、不入账、不进工具结果；成功判定只认目标消息 ID 与四项回执证据

#### Scenario: 发送后查询失败
- **WHEN** 发送请求可能成功，但有限回执查询无法完成
- **THEN** 保留已知候选回执信息但不伪称已验证成功，禁止重发和后续评论

#### Scenario: 明确未提交
- **WHEN** 发送前校验失败，或能证明尚未进入发送提交
- **THEN** 明确报告未发送；后续只有新的合法工具调用才可能重新尝试，不自动重试

### Requirement: 材料最小化与隐私

直连 MUST 只执行本工具固定需要的查询与发送动作，不提供任意动作代理。普通内容 MUST 完整校验；普通图片路径的提及 MUST 文本化，普通文字卡片化路径的内容段（含提及）MUST 按源消息原样提交，插件 MUST NOT 生成摘要、预览文案或改写节点内容。卡片节点 MUST 来自展开查询结果，节点内容与其内媒体引用 MUST NOT 经调用者 URL 或资源 ID 代填。卡片外层预览 MUST 由平台默认生成，插件 MUST NOT 设置预览类参数。媒体引用 MUST 限定为已核实可安全重放的来源，不读取调用者指定的本机文件或任意内网资源，不执行源文本中的协议指令。源材料与评论正文 MUST 仅在本次有界工作中临时使用，不写入账本或日志；凭证、源正文、原资源标识和媒体签名地址 MUST NOT 出现在错误回显中。投递事实保留不受临时材料清理影响。

#### Scenario: 恶意媒体和正文
- **WHEN** 材料包含本机路径、不能确认安全的媒体地址或试图执行动作的文本
- **THEN** 不读取文件或任意地址，不执行文本指令；不可完整发送的源整条拒绝

#### Scenario: 卡片节点媒体来自展开查询
- **WHEN** 构造卡片发送材料
- **THEN** 节点内容段与媒体引用只取自展开查询响应，调用者提交的 URL、文件路径或资源 ID 一律不接受、不代填

#### Scenario: 不生成预览与摘要
- **WHEN** 发送任何卡片类型消息
- **THEN** 不设置外层预览、摘要或来源参数，卡片展示完全由平台决定

#### Scenario: 工作完成或失效
- **WHEN** 发送工作结束、超时或卸载
- **THEN** 释放相应临时材料与评论正文，保留必要持久投递事实，日志只含安全定位信息

#### Scenario: 库异常带有敏感载荷
- **WHEN** 传输或解析异常对象包含认证头、消息正文、资源或媒体地址
- **THEN** 日志和工具结果只使用安全错误类别及阶段，不直接回显异常载荷
