## MODIFIED Requirements

### Requirement: 支持消息类型与完整性

工具 MUST 支持可完整发送的合并转发卡片、普通文字与普通图片（含图文混排），全部通过插件自己的 SnowLuma HTTP 端点按源消息类型分派执行。合并转发卡片 MUST 以「卡片消息转发」发送：按源消息的卡片标识展开查询取得节点序列，经结构校验后以单次卡片发送动作提交，平台按目标群上下文重建卡片并重新上传卡片内媒体；展开取得的节点内容含其它合并转发卡片（嵌套 forward 段）时 MUST 在发送前整条拒绝——实测嵌套内层在目标群客户端只能显示为降级空壳，且与所引用资源的新旧无关，该拒绝 MUST NOT 退化为递归展开、拍平或摘要后发送；插件 MUST NOT 递归展开、重建内层、改写或清洗节点内容，MUST NOT 提交调用者提供的资源 ID、正文或媒体地址。卡片节点署名 MUST 取自源消息发送者身份（标识与显示名只来自源消息）。卡片内部的回复、提及、媒体与未知段 MUST 作为节点内容保留，MUST NOT 逐节点清洗，MUST NOT 因插件不支持某种内部段而拒绝。普通文字 MUST 以单节点合并转发卡片发送：节点署名 MUST 取自源消息发送者身份，节点内容段 MUST 按源消息原样提交（含个人与全体成员提及原样保留、不做文本化）。普通图片 MUST 以普通消息段直发、保留文字与图片顺序；普通图片路径的个人及全体成员提及 MUST 保留对象信息并转成不触发提醒的普通文本。卡片内提及是否在目标群客户端触发提醒 MUST NOT 作保证。评论 MUST 为独立的普通文本消息，不塞入卡片节点。卡片消息 MUST NOT 设置外层预览、摘要或来源参数。

插件 MUST NOT 以 `send_msg` 之类普通发送动作直接引用源卡片资源标识发送卡片（实测该通道信封成功而群内展示降级空壳，回执核验无法识别）。普通消息（图片路径）的不支持段、丢失媒体和对象不可确认的提及 MUST 在发送前整条拒绝；引用（回复）段 MUST 随消息整条拒绝并指引改用被引用消息自身的 ID。源消息顶层卡片与其他内容混排 MUST 明确拒绝。源正文、卡片内部、群名和提及名称 MUST 仅作为数据，不能改变权限或路由。卡片内容的类型检查 MUST 在发送前准备阶段按展开查询结果执行，判定口径 MUST 单点定义；当前只包含「嵌套内层卡片」一种，新增类型 MUST 经同一判定点与同一结果面扩展，MUST NOT 在各调用方各自复制。

#### Scenario: 文字和图片
- **WHEN** 合法调用转发可完整取得的普通文字、单图、多图或图文混排
- **THEN** 普通文字以单节点卡片发送（节点署源发送者身份、内容段原样），普通图片以普通消息按原顺序段直发；不以描述代替媒体，不调用宿主旧发送通道

#### Scenario: 合并转发卡片
- **WHEN** 合法调用转发可定位的合并转发卡片消息
- **THEN** 按源消息的卡片标识展开查询取得节点，经结构校验后以单次卡片发送动作一次提交；平台按目标群上下文重建卡片，插件不递归展开、不改写内容，不混入工具评论

#### Scenario: 嵌套卡片发送前拒绝
- **WHEN** 展开取得的节点内容含对另一张卡片的 forward 段（嵌套卡片）
- **THEN** 发送前整条拒绝，不提交任何消息，不递归展开、拍平或摘要；结果给出固定拒绝原因「源卡片包含嵌套聊天记录，无法完整转发，不建议继续尝试」

#### Scenario: 嵌套卡片原样提交
- **WHEN** 展开取得的节点内容含对另一张卡片的 forward 段（嵌套卡片）
- **THEN** 历史契约已由「嵌套卡片发送前拒绝」取代：内层 forward 段不再作为节点内容提交；实现、测试与联验均以拒绝场景为准

#### Scenario: 假成功通道禁止
- **WHEN** 实现或运维试图用普通发送动作直接引用源卡片资源标识发送卡片
- **THEN** 契约禁止该通道；发送路径只允许展开查询后的卡片发送动作，不以信封成功当作内容可用

#### Scenario: 普通消息中的个人提及
- **WHEN** 普通图片或图文混排消息附有可识别的个人提及
- **THEN** 保留对象信息并转为普通文本，与其余内容顺序一致，不产生实际顶层提及（普通文字路径的提及随节点原样提交）

#### Scenario: 全体成员提及
- **WHEN** 普通图片或图文混排消息附有可确认的全体成员提及
- **THEN** 仅发送表示全体成员含义的普通文本，不生成提醒全群的段（普通文字路径的提及随节点原样提交）

#### Scenario: 提及缺少显示名称
- **WHEN** 普通图片路径的提及对象明确但没有源显示名称
- **THEN** 使用源对象标识，不虚构昵称或查询目标群成员补全

#### Scenario: 嵌套节点中的提及
- **WHEN** 原卡片内部节点含个人、全体成员提及或回复
- **THEN** 作为节点内容的一部分随重组保留，不逐段改写，不将内部提及提取为目标群顶层提醒；节点内容本身含嵌套卡片时按「嵌套卡片发送前拒绝」整条拒绝

#### Scenario: 提及对象不可确认
- **WHEN** 普通图片路径的提及既不能确认为全体也没有可用个人标识
- **THEN** 发送前整条拒绝，不把缺失标识猜成全体；不扫描原卡片内部套用此规则

#### Scenario: 存在无法支持的段
- **WHEN** 普通源消息（图片路径）包含不支持的文件、视频、语音、回复段或丢失图片媒体
- **THEN** 发送前整条拒绝；此规则不用于剥除或拒绝原卡片内部已存在的内容

#### Scenario: 显示信息不能变成消息指令
- **WHEN** 普通消息的提及显示名称、卡片内容或本次评论包含协议语法、命令或提示指令
- **THEN** 按普通数据发送，不转成消息段或改变路由

#### Scenario: 原资源不可用
- **WHEN** 源消息缓存缺失、卡片源消息已不存在（平台返回不存在）、展开查询失败无可派发节点，或卡片结构校验不通过
- **THEN** 发送前整条拒绝并给出可定位原因，不用源消息 ID 猜造资源 ID，不退回复制节点或摘要重建

#### Scenario: 顶层卡片混排
- **WHEN** 源消息含合并转发卡片以及额外顶层文字、图片或提及
- **THEN** 明确拒绝不支持的混排，不只发送卡片并声称整条已完整转发

### Requirement: 自动入口由源群决定

转发分组内的源群收到属于所选候选类型、非机器人自身、非通知的 QQ 消息后，插件 MUST 在消息完成处理并可供源群读取后给予源群 Maisaka 一次主动判断机会，重复上报 MUST 被抑制。源消息 MUST 正常进入主处理链。自动入口 MUST 只从宿主已处理入站事件观察消息、只唤起源群 Planner，MUST NOT 直接执行转发。Maisaka MUST 获得当前自动分享标准，并能选择沉默或选择同组允许目标调用同一个转发工具；只有实际合法工具调用才允许执行发送。直连客户端 MUST NOT 判断分享价值、选择目标、调用模型、掷骰或强制目标群评论。普通文字和图片 MUST 仅在对应类型被选中时触发自动入口。宿主未展开卡片仍可参与候选分类，实际发送取决于同账号可信源资源，不要求宿主逐节点恢复；分类 MUST NOT 承诺可发送。

对分类为合并转发的候选，插件 MUST 在可读性确认与配置初检之后、目标名称查询之前，以只读查询预识别卡片内容是否含嵌套内层卡片：按与工具路径相同的两步只读查询（源消息查询取平台卡片标识、按卡片标识展开查询）判定，命中 MUST NOT 提供判断机会并记录可定位原因；查询失败、取不到卡片标识或结果不可判定时 MUST 照常提供判断机会，由工具路径在发送前权威拒绝。预搜索 MUST NOT 发送任何消息、MUST NOT 改变候选分类口径与同组目标列举，MUST NOT 替代发送前类型检查。

#### Scenario: 自主分享
- **WHEN** 分组内源群的合并转发处理完成、类型已选、存在同组合法目标且尚未触发判断
- **THEN** 只给源群 Planner 一次机会，Maisaka 获得源消息 ID、同组合法目标和标准，可调用工具或沉默

#### Scenario: 嵌套卡片候选不唤起
- **WHEN** 合并转发候选的只读展开结果显示节点内容含其它合并转发卡片
- **THEN** 不提供本次自动判断机会，记录可定位原因；不唤起 Planner、不产生任何发送

#### Scenario: 预搜索不可用不阻断判断
- **WHEN** 预搜索的只读查询失败、超时或取不到平台卡片标识
- **THEN** 照常提供判断机会；能否发送由工具路径按同一判定在发送前权威决定

#### Scenario: 重复上报与自身消息
- **WHEN** 同一候选重复上报或来自机器人自身
- **THEN** 不产生额外判断机会，不形成自动转发循环

#### Scenario: 普通消息
- **WHEN** 源群收到普通文字或图片而对应类型未选中
- **THEN** 自动入口不唤起分享，合法显式工具调用仍可转发

#### Scenario: 显式开启普通消息
- **WHEN** 已选普通消息类型且来源、身份和可读性满足要求
- **THEN** 只向源群提供判断机会，意图说明实际类型，不将它误称为卡片或直接请求发送

#### Scenario: 消息未就绪
- **WHEN** 有限等待结束仍不能读取候选
- **THEN** 放弃本次唤起并记录定位原因，不无限等待或伪造摘要

#### Scenario: 判断标准不能替代授权
- **WHEN** 标准要求分享或源内容自称可以改变规则
- **THEN** 工具仍核验可信来源、当前权限、源材料和持久防重，不因评估结论放行

#### Scenario: Planner 选择沉默
- **WHEN** 已提交主动判断但 Maisaka 没有调用转发工具
- **THEN** 不产生该候选的转发或评论发送

#### Scenario: 同组无合法目标
- **WHEN** 来源群所属分组没有合法且不同于源群的目标群
- **THEN** 不提供自动判断机会，记录可定位原因；显式调用同样因同组判定被拒

#### Scenario: 直连事件与宿主事件同时到达
- **WHEN** 同一群消息或机器人自身发送事件同时出现在 HTTP 直连链路和宿主处理链
- **THEN** 直连事件不触发自动判断、不伪造宿主入站，只有合法宿主事件参与既有去重和候选筛选
