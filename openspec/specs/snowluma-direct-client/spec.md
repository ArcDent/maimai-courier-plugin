# snowluma-direct-client Specification

## Purpose

定义麦麦搬运喵在插件进程内直连 SnowLuma 已有正向 WebSocket 服务端的可观察契约：受控连接与同账号查询、可信源材料、多客户端并存下的响应关联、真实回执和不确定结果保护，保持现有宿主入站处理与其他客户端不受影响，不依赖适配器公开 API 或新增独立服务。

## Requirements

### Requirement: 正向连接与受控认证

插件 MUST 主动连接操作者配置的单一 SnowLuma WebSocket 服务端，不创建反向 WebSocket 或 HTTP 监听服务。地址、可选令牌 `snowluma.token` 与凭证环境变量名 MUST 只来自插件受控配置。非空且非全空白的配置令牌 MUST 优先使用；令牌留空或全空白时 MUST 仅在建立连接时从指定环境读取凭证，不读取其他插件配置、运行凭证或模型参数。配置令牌允许明文保存在插件配置文件，操作者 SHOULD 限制文件权限并避免提交真实令牌到仓库。连接 MUST 默认验证对端证书，不跟随会泄露认证信息的重定向；明文连接 MUST 仅在目标解析为回环、私有或链路本地地址时允许，公网目标必须使用 `wss`，且该判定 MUST 在建立连接前完成；凭证 MUST NOT 放入 URL、日志、账本或工具结果。配置缺失或认证失败 MUST 安全停止直连发送，仍允许插件注册工具并给出原因；总开关关闭时 MUST 不因工具调用建立发送连接或提交动作。

#### Scenario: 与现有适配器并存
- **WHEN** 操作者配置的是已有客户端连接的 SnowLuma 服务端
- **THEN** 本插件只建立自己的客户端连接，不接管适配器连接、不要求新服务进程、不修改服务端端点或现有客户端设置

#### Scenario: 地址或凭证未完成
- **WHEN** 连接地址为空、非法、使用未保护的远程连接，或未填写令牌且凭证环境变量缺失
- **THEN** 不建立连接、不发送，返回可定位原因，不从其它插件读取配置或凭证补齐

#### Scenario: 配置令牌与环境变量兼容
- **WHEN** 操作者填写非空且非全空白的 `snowluma.token`
- **THEN** 使用该令牌认证，不要求环境变量存在，也不因认证失败改用环境变量重试；留空或全空白时沿用建连时读取 `token_env_var` 的方式

#### Scenario: 配置令牌热更新
- **WHEN** 源或评论尚未提交时配置令牌发生变化
- **THEN** 旧阶段失效，不沿旧连接继续提交；后续合法新调用使用新配置且仍受持久防重约束

#### Scenario: 认证重定向
- **WHEN** 配置端点在握手时返回重定向
- **THEN** 拒绝继续认证，不向重定向目标发送凭证，不把重定向当作自动发现服务

#### Scenario: 默认关闭
- **WHEN** 总开关关闭且收到工具请求或自动候选
- **THEN** 不为该请求建立直连、不执行平台动作、不唤起自动分享


### Requirement: 同账号查询与源材料可信性

直连实际登录账号 MUST 与可信宿主调用账号一致；目标群 MUST 为该账号可确认的合法目标。插件 MUST 先验证宿主源消息归属，再按已核实的标识对应关系查询同账号 OneBot 源消息并验证群归属，不能仅凭可解析的 ID 就认定对应关系成立。源材料 MUST 来自该可信源消息，不能接受模型提交的正文、卡片资源 ID、媒体地址或账号信息。连接重建或账号变化 MUST 使旧账号核验失效，不得在核验后静默切换连接账号发送。

#### Scenario: 错误账号
- **WHEN** 服务端实际登录账号与可信工具调用账号不同
- **THEN** 在源查询或发送前拒绝，不切换账本键规避差异，不使用另一个端点或账号重试

#### Scenario: 查询返回另一群
- **WHEN** 查询响应中的源群与可信源群不符
- **THEN** 不发送、不把响应正文泄露给模型、不使用其资源构造消息

#### Scenario: 标识对应不足
- **WHEN** 只有宿主内部消息标识，且无法确认对应的 OneBot 消息标识
- **THEN** 明确拒绝，不能截取、重编码或猜测标识后发送

#### Scenario: 核验后连接重建
- **WHEN** 已核对账号的连接在实际发送提交前断开
- **THEN** 该阶段不在新连接上自动继续发送；旧核验失效，只有后续合法新调用在重新核验并通过账本防重后才可能发送


### Requirement: 动作关联与事件隔离

每个请求 MUST 使用可区分本插件运行实例、连接及本次动作的关联标识，只有当前连接中与待决请求准确匹配且结构合法的动作响应才允许推进结果。平台事件、其他客户端响应、无关联响应、超时后的迟到响应和旧连接响应 MUST NOT 被当作当前动作回执。所有来自直连的普通群消息、通知和自发事件 MUST NOT 唤起 Planner、执行转发、伪造宿主入站或补写目标群历史；连接管理事件只允许影响连接状态，不具有发送授权作用。

#### Scenario: 事件先于动作响应
- **WHEN** 一个动作等待期间先收到群消息、心跳或自发事件，再收到其匹配响应
- **THEN** 前述事件不触发分享或错误完成动作；只有合法匹配响应参与该动作判定

#### Scenario: 其他客户端和迟到响应
- **WHEN** 收到无关关联标识、已超时动作响应或上一连接的迟到响应
- **THEN** 不完成当前动作、不修改不相干投递记录、不引发额外发送

#### Scenario: 伪装成响应的事件
- **WHEN** 收到带有匹配关联字段但同时属于平台事件、或响应结构缺失的载荷
- **THEN** 不仅凭关联字段把它当作成功回执，按非法响应保守处理


### Requirement: 有界动作与不重放

动作排队、连接建立、账号及消息查询、发送等待、回执核验和连接关闭 MUST 有代码常量规定的有限上界，等待、在途请求与事件处理 MUST 不无限积压。重复事件 MUST NOT 重置动作总期限。断线后可以为后续合法操作重建同一受控端点连接，但 MUST NOT 自动重放旧的源或评论发送动作、切换动作或切换通道探测结果。尚未进入发送提交且可以证明未提交的操作 MUST 报告明确未发送；已开始写入或无法证明未提交的操作 MUST 按真实证据或待核实处理。

#### Scenario: 断线前后
- **WHEN** 发送帧可能已写出后连接断开且无可靠回执
- **THEN** 当前阶段保持待核实，重建连接不重放该帧；同一投递的后续工具调用被账本阻断

#### Scenario: 排队期间撤销权限
- **WHEN** 动作仍在等待发送资格时总开关关闭、权限收缩或插件卸载
- **THEN** 该动作在取得执行机会后仍须复验，不提交已失效发送，明确报告未发送

#### Scenario: 事件持续到达
- **WHEN** WebSocket 持续推送与当前动作无关的事件
- **THEN** 动作仍按原总期限结束，事件不无限占用内存或阻止卸载退出

#### Scenario: 并发容量耗尽
- **WHEN** 本插件在途或等待工作达到代码规定的容量上限
- **THEN** 新工作在提交前明确拒绝，不挤掉已知成功记录或强制重发在途动作


### Requirement: 真实回执与安全结果分类

一次源或评论发送 MUST 最多提交一个发送动作。只有合法动作响应与可核实的真实平台目标消息身份一致时，才允许确认发送成功；仅有非空消息 ID、资源 ID、本地不透明 ID 或受理标志 MUST NOT 视为成功。回执核验 MUST 确认目标群、发送账号及平台消息证据，查询次数 MUST 有限且仅针对该次返回的目标标识，MUST NOT 通过再次发送来核实。模糊失败、未知返回状态、缺失关键证据、查询超时、取消及无法判断是否已提交的异常 MUST 保守归为待核实，不能用通用错误码猜成可重试失败。

#### Scenario: 成功响应但标识不足
- **WHEN** 动作报告成功但没有可核实的真实目标消息标识
- **THEN** 不报告完整成功，不自动重试，源未知时不发送评论

#### Scenario: 回执不属于本次投递
- **WHEN** 查询所得目标群、发送账号或平台消息证据与本次请求不匹配
- **THEN** 保持待核实，不把其他群或其他账号的消息记为本次成功

#### Scenario: 发送后查询失败
- **WHEN** 发送动作可能成功，但有限回执查询无法完成
- **THEN** 保留已知候选回执信息但不伪称已验证成功，禁止重发和后续评论

#### Scenario: 明确未提交
- **WHEN** 发送前校验失败，或传输能证明尚未进入动作提交
- **THEN** 明确报告未发送；后续只有新的合法工具调用才可能重新尝试，不自动重试


### Requirement: 材料最小化与隐私

直连 MUST 只执行本工具固定需要的查询与发送动作，不提供任意动作代理。原卡片 MUST 仅复用可信资源；普通内容 MUST 完整校验并统一提及文本化。媒体引用 MUST 限定为已核实可安全重放的来源，不读取调用者指定的本机文件或任意内网资源，不执行源文本中的协议指令。源材料与评论正文 MUST 仅在本次有界工作中临时使用，不写入账本或日志；凭证、源正文、原资源标识和媒体签名地址 MUST NOT 出现在错误回显中。投递事实保留不受临时材料清理影响。

#### Scenario: 恶意媒体和正文
- **WHEN** 材料包含本机路径、不能确认安全的媒体地址或试图执行动作的文本
- **THEN** 不读取文件或任意地址，不执行文本指令；不可完整发送的源整条拒绝

#### Scenario: 工作完成或失效
- **WHEN** 发送工作结束、超时或卸载
- **THEN** 释放相应临时材料与评论正文，保留必要持久投递事实，日志只含安全定位信息

#### Scenario: 库异常带有敏感载荷
- **WHEN** 传输或解析异常对象包含握手头、消息正文、资源或媒体地址
- **THEN** 日志和工具结果只使用安全错误类别及阶段，不直接回显异常载荷
