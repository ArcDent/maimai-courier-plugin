# 原卡片转发保留内部内容，不逐段改写提及

> 2026-10-02：原卡片内部保留的决定继续有效；发送接入位置改由 [ADR 0006](0006-forward-via-snowluma-adapter-api.md) 的适配器公开 API 方案接续。下文关于独立服务的描述保留为历史，不要求本轮继续部署独立服务，真实 QQ 联验仍未完成。

用户确认合并转发应以整张已有卡片为对象转发，内部存在回复或个人、全体成员提及不应单独导致拒绝；不再为了将内部提及转成普通文本而展开、重建卡片。是否分享、选择哪条源消息及目标群，仍由源群 Maisaka 判断并发起工具调用，SnowLuma 侧负责执行实际转发。

这项决定在“原卡片转发”范围内调整 [ADR 0002](0002-cross-group-mentions-without-notifications.md)：用户明确表示内部提及保留即可，卡片内的提及转换逻辑可以删除。它不授权静默丢弃内容，也不要求额外生成新的顶层提及；平台如何呈现卡片内部提及是待验证事实，本记录不声称已证明绝不提醒。后续已确认普通文字、图片及评论也迁移到新服务，但普通消息的提及转文本规则未另行改变；发送位置迁移不等于删除所有提及处理。

保留内部资源可以避免因插件不支持某种节点而重建失败，但无法同时修改该资源中的提及。这是选择原卡片保真、放弃卡片内逐段清洗的明确取舍。外层预览是否完全一致、旧资源可用性仍受网关和平台行为限制，不能由该决定保证。

新增独立服务器／客户端及 Maisaka 保留工具调用职责，已由 [ADR 0005](0005-separate-snowluma-forward-service.md) 确认；用户同时接受独立服务转发不保证目标群 Maisaka 历史同步。具体接入位置、路由与防重如何衔接已在该变更 design 中确定（客户端阶段授权 + 服务端唯一账本）并完成实现；**真实 QQ 联验尚未执行，本记录不能被视为已通过联验**。
