# 跨群转发保留提及对象信息，但不传播提醒

源消息或合并转发节点中的 `at` 段目前会使整条消息在内容预检时被拒绝。用户已确认：转发时保留被提及对象的信息，但将提及转换为普通文本；个人提及与全体成员提及均不得在目标群形成实际的 @ 提醒。

这是对「普通消息保持原有形态」的一项明确、有限的例外：保留内容所指对象，不把源群的通知行为带到另一个群。相比原样发送真正的提及，这一选择避免产生跨群提醒；相比直接丢弃提及段，它保留原消息的语义信息。此例外不授权丢弃其他消息段，不改变媒体完整性、白名单、投递防重与回执要求。

本记录只确认产品语义。宿主提供的提及字段、可用显示信息与发送侧行为仍待只读核实，具体文本格式与验收场景由后续规格确定；当前尚未修改业务代码。
