# 将自动候选类型与自动分享标准分别交给用户配置

用户已确认将自动入口从固定的合并转发候选扩展为可选的文字、图片、合并转发，并将内容偏好作为独立、全局、多行可编辑的自动分享标准。默认仍仅合并转发；图文混排归为图片，默认标准延续自主判断与可以沉默，不预设特定主题。

候选类型决定哪些消息值得发起一次模型评估，分享标准描述评估时的内容偏好；二者不能混为转发权限或工具的消息支持能力。标准只约束自动评估，不为群友明确请求增加偏好限制；白名单、来源凭据、内容完整性和持久防重始终生效。尚未发起的自动评估使用最新配置，不追回或伪装撤销已提交给模型的判断。

放开普通消息的自动候选可能增加模型调用，因此由用户显式启用，默认不扩大既有触发面；不以暗藏概率或冷却规则抵消这一选择。该决定替代原来「普通文字与图片永不自动触发」的产品边界，但保留源群自主判断、目标群不另行唤起的原则。当前仅确认需求，业务实现与主规格同步尚未进行。
